# Słówka — nauka hiszpańskiego, włoskiego i angielskiego

Statyczna aplikacja (HTML/CSS/JS), bez serwera i bez kont. Postępy zapisują się w przeglądarce użytkownika (localStorage), więc każdy, kto otworzy link, ma własne wyniki.

## Publikacja na GitHub Pages
1. Załóż konto na github.com i utwórz nowe publiczne repozytorium (np. `slowka`).
2. Wgraj wszystkie pliki z tego folderu (Add file → Upload files), łącznie z folderem `data`.
3. Settings → Pages → Source: „Deploy from a branch”, gałąź `main`, folder `/ (root)`.
4. Po minucie aplikacja będzie pod adresem `https://TWOJA-NAZWA.github.io/slowka/`.

## Instalacja na iPhonie
Safari → otwórz link → przycisk Udostępnij → „Dodaj do ekranu głównego”.

## Kursy
- Español, Italiano, English (B2 → C1)
- English B1–B2 (kurs `en2`, 1000 słówek B1 → B2, USA) — pliki danych: `data/en2-1..4.js`, `tr-en2-1..4.js`, `ph-en2*`, `rd-en2-*`. Używa tego samego głosu angielskiego co kurs English.
